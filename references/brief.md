# Project Brief

## Overview

This project is a complete redesign and rebuild of Álvaro Mena’s personal portfolio website.

The goal is to create a modern, systems-oriented portfolio that communicates senior-level engineering experience, frontend architecture expertise, design sensitivity, and technical leadership through both content and interface design.

The site should feel intentional, structured, editorial, and highly curated. It must balance technical credibility with strong visual identity while remaining performant, maintainable, and accessible.

The portfolio is not intended to feel like a generic developer template or startup landing page. The experience should reflect architectural thinking, systems design, and long-term craftsmanship.

# Visual Identity

## Typography

### Display Typeface

- DM Serif Display

Used for:

- Large editorial headings
- Hero statements
- Section titles
- Key visual moments

### Body Typeface

- Roboto Mono

Used for:

- Body copy
- Interface text
- Navigation
- Technical metadata
- Labels
- Supporting content

The contrast between serif editorial typography and monospaced technical typography is a core part of the identity system.
